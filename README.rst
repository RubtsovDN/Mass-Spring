    :Тип научной работы: FDA

Abstract
========
В данной работе обучается модель для решения системы уравнения движения системы два груза - две пружины - два демпфера (аналог демпфирующей системы автомобиля). Исследуется устойчивость модели к интервенции занулением признака с помощью критерия Колмогорова-Смирнова. Генерируются вычислительные графы измененного уравнения движения системы, учитывающей его сложность, устойчивость к интервенциям и, конечно, точность модели с помощью нормализующих потоков на графах
